## 📌 About the Project

The **Mobile Information Management System** is a console-based C program designed to store and manage information about mobile phones.

The system allows users to:

- Enter information about multiple mobile phones
- Store brand, model, color, price, and storage capacity
- Calculate the minimum mobile price
- Calculate the maximum mobile price
- Calculate the average mobile price
- Search for mobile phones by brand name

The project demonstrates the use of fundamental C programming concepts such as **2D arrays, functions, loops, conditional statements, strings, and basic data processing**.

---

## ✨ Features

### 📥 Insert Mobile Information
Users can enter:

- Brand
- Model
- Color
- Storage Capacity (GB)
- Price

### 📊 Price Statistics

The program calculates:

- Total number of mobiles
- Minimum price
- Maximum price
- Average price

### 🔎 Search by Brand

Users can search for mobile phones using their brand name.

If a matching brand is found, the program displays the complete information of the mobile.
